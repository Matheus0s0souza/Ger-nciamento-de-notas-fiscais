# Ger-nciamento-de-notas-fiscais
Desenvolvimento de projeto para otimização do processo de escaneamento e armazenamento de notas fiscais e canhotos de entrega, melhorando a organização documental e agilizando o acesso às informações. A solução também trouxe ganhos para a área de logística, gerando economia de tempo, combustível e custos operacionais.
